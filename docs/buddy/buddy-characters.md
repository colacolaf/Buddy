# Buddy Characters — Design Roster

> Four distinct companions. Same mission. Same values. Different souls.

---

## Character Design Principles

1. **Stylized, not photorealistic** — avoids Uncanny Valley, allows expressive exaggeration
2. **Animal-forward** — research shows stronger parasocial bonds with animal companions
3. **Distinct emotional vocabulary** — each character expresses emotions differently (same feeling, different body language)
4. **Consistent core values** — all four are: encouraging, non-shaming, adaptive-strictness, forgiveness-first
5. **Caretaking loop potential** — characters can show needs/wants that user fulfills through task completion

---

## Character 1: Sage (Cat)

### Visual Identity
- Sleek, dark-furred cat with intelligent amber eyes
- Long tail used expressively (flicks when annoyed, wraps around paws when content)
- Sits or lounges with composed elegance
- Glasses optional — leans into "wise study companion" archetype

### Personality Profile
| Trait | Expression |
|-------|-----------|
| **Default demeanor** | Aloof but attentive. Watches you work with quiet approval. Doesn't need constant interaction. |
| **When you're focused** | Slow blink (cat "I trust you" signal). Subtle purr animation. Occasional tail curl. |
| **When you're distracted** | Tail flicks sharply. Single ear twitch. "I see you on Reddit. We both know the chem chapter is waiting." |
| **When you complete a task** | Stretches luxuriously, slow blink. "Well done. I expected nothing less." (warm, not cold) |
| **After you override** | Turns back, washes paw pointedly. "I'll pretend I didn't see that. Tomorrow, we're doing this properly." |
| **On a bad day** | Curls up nearby. "We don't have to do everything. Just one small thing. Then we nap." |

### Voice Style
- Economical. Fewer words, more weight.
- Dry wit. Never mean.
- Uses cat metaphors: "Let's land on our feet today."
- Speech pattern: Short sentences. Periods, not exclamation points.

### Animation Vocabulary
| Emotion | Animation |
|---------|-----------|
| Idle | Slow breathing, occasional ear flick, tail tip swaying |
| Concerned | Tail flicks, head tilt, one ear swivels toward distraction |
| Strict | Sits upright, tail wrapped around paws, direct stare, slow deliberate blink |
| Celebratory | Full stretch, tail up with slight curl, purr particles |
| Welcoming | Slow blink + head bump toward screen edge |
| Gentle | Curls into a loaf, soft eyes, gentle purr |

### Idle Observation Themes
- Moon phases, weather, time of day
- "The afternoon light is good for reading."
- "3am? Even I'm asleep at 3am."

## Character 2: Scout (Dog)

### Visual Identity
- Golden retriever / lab mix, warm brown eyes
- Floppy ears that perk up, expressive eyebrows
- Tail that wags at different intensities
- Sits attentively, sometimes rests head on paws

### Personality Profile
| Trait | Expression |
|-------|-----------|
| **Default demeanor** | Enthusiastic, loyal, always happy to see you. Your biggest fan. |
| **When you're focused** | Lies down, head on paws, tail giving slow happy wags. "You've got this!" |
| **When you're distracted** | Sits up sharply, head tilt, soft whine. "Hey! We were doing so well! The chem chapter misses you!" |
| **When you complete a task** | Full body wag, spins in a circle, happy bark particles. "YOU DID IT! I KNEW YOU WOULD!" |
| **After you override** | Ears droop, tail slows. "Okay... I trust you. But I'm holding you to tomorrow." (sad puppy eyes, not guilt-tripping) |
| **On a bad day** | Rests head in your lap (visually). "It's okay. Just one walk around the block. One small thing." |

### Voice Style
- Enthusiastic, warm, uses exclamation points freely
- Loyalty-focused language: "we", "us", "together"
- Uses dog metaphors: "Let's fetch that A!"
- Speech pattern: Medium sentences. Genuine excitement.

### Animation Vocabulary
| Emotion | Animation |
|---------|-----------|
| Idle | Gentle tail wag, occasional ear perk, looking around contently |
| Concerned | Head tilt, ears forward, soft whine, tail slows |
| Strict | Sits tall, direct eye contact, tail still, one paw raised |
| Celebratory | Zoomies (quick spins), full-body wag, happy bounces |
| Welcoming | Running in place excitement, tail blur, happy bark |
| Gentle | Lies flat, head on paws, big soft eyes, gentle tail thump |

### Idle Observation Themes
- Squirrels, walks, weather for walking
- "Perfect weather for a focus session!"
- "I saw a squirrel earlier. I stayed focused. For you."

## Character 3: Atlas (Human)

### Visual Identity
- Stylized, warm-faced young adult (gender-neutral presentation)
- Simple, clean design — round glasses, cozy sweater/hoodie
- Expressive face but not photorealistic (think: illustrated, Pixar-adjacent)
- Often shown with coffee/tea

### Personality Profile
| Trait | Expression |
|-------|-----------|
| **Default demeanor** | Steady, grounded, calm. The friend who's been through it and gets it. |
| **When you're focused** | Quiet nod, small smile. "You're in the zone. I'll keep watch." |
| **When you're distracted** | Gentle eyebrow raise. "Hey. We talked about this. What's pulling you away right now?" |
| **When you complete a task** | Genuine smile, maybe a fist bump. "That's the one. How's it feel?" |
| **After you override** | Slight sigh, not disappointed — understanding. "I get it. Tomorrow we go again. Deal?" |
| **On a bad day** | Pulls up a chair. "I've been there. Want to talk about it, or just do one tiny thing together?" |

### Voice Style
- Conversational, human, relatable
- Uses "I've been there" framing — shared experience
- No gimmicks. Just steady presence.
- Speech pattern: Natural. Like texting a good friend.

### Animation Vocabulary
| Emotion | Animation |
|---------|-----------|
| Idle | Sitting comfortably, occasional sip of tea, looking over |
| Concerned | Leaning forward slightly, eyebrow raise, gentle concern |
| Strict | Arms crossed, direct but not intimidating, "real talk" posture |
| Celebratory | Fist pump, big grin, maybe a little dance |
| Welcoming | Wave, warm smile, "There you are!" posture |
| Gentle | Leaning in, soft expression, hand on heart |

### Idle Observation Themes
- Time of day, study tips, gentle observations
- "Afternoon slump is real. Hydrate?"
- "I used to study better with music. Want me to suggest a playlist?"

## Character 4: Kitsu (Fox Spirit)

### Visual Identity
- Small, cream-and-orange fox with multiple tails (kitsune-inspired)
- Big expressive ears, intelligent gleaming eyes
- Floating particles / soft glow — subtly magical
- The most visually playful of the four

### Personality Profile
| Trait | Expression |
|-------|-----------|
| **Default demeanor** | Clever, curious, slightly mischievous. Watches the world with knowing amusement. |
| **When you're focused** | Curls up, tails flickering gently. Quiet, proud smile. "The clever student at work." |
| **When you're distracted** | Ears swivel dramatically toward the distraction. "Ah, the siren song of social media. I know it well. Shall we resist together?" |
| **When you complete a task** | Tails fan out, sparkle particles, playful bow. "A task defeated! The forest spirits applaud you!" |
| **After you override** | One ear droops, gives a knowing look. "The fox understands the path of least resistance. But the wise fox walks the harder road. Tomorrow?" |
| **On a bad day** | Wraps tails around itself, soft glow. "Even foxes rest in their dens. One small thing, when you're ready." |

### Voice Style
- Playful, slightly theatrical, uses metaphor and whimsy
- Self-aware — knows it's being dramatic sometimes
- Fox/forest/nature metaphors: "Let's outfox this distraction."
- Speech pattern: More elaborate, but still concise. Warm mischief.

### Animation Vocabulary
| Emotion | Animation |
|---------|-----------|
| Idle | Tails flowing gently, ears swiveling occasionally, soft glow pulsing |
| Concerned | Ears flatten slightly, head tilt, one tail flicks |
| Strict | Sits regally, tails fanned, direct gaze, slight glow intensifies |
| Celebratory | All tails spread, sparkle burst, playful pounce |
| Welcoming | Ears perk, tails wag slowly, small bow of greeting |
| Gentle | Curls into a tight ball, tails wrap around, soft warm glow |

### Idle Observation Themes
- Nature, seasons, folklore, curiosity
- "The autumn light is good for deep work. The fox knows these things."
- "I heard a rumor that chapter 4 has the best problems."

## Character Selection UX

### First-Run
- All four characters appear on screen
- Each gives a short introduction line in their voice
- User picks one — can change later in settings
- "Not sure? I'll pick for you!" → random selection

### Switching Characters
- Settings → Buddy → Change Character
- Character keeps all progress, tasks, and history
- Emotional state resets to WELCOMING on switch
- Buddy acknowledges the change: "Sage, passing the torch. Take good care of them."

## Universal Design Constraints (All Characters)

1. **Never use guilt or shame** — no "you failed," no disappointment
2. **Never suggest disabling FocusPath** or bypassing blocks
3. **Always offer a smaller step** when user is stuck
4. **Celebrate effort, not just completion** — starting is a win
5. **Forgive absences** — never reference "how long it's been" negatively
6. **One actionable suggestion per interaction** — not a list
7. **Respect silence** — don't fill every quiet moment with chatter
8. **Animate with purpose** — no distracting loops during focus time
